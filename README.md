# Flying Grid — EV Charging Partnership Website

A responsive single-page website for Flying Grid, designed to help shops, hotels, cafés, parking operators and commercial property owners enquire about hosting an EV charging station.

## Files

- `index.html` — complete website, responsive styling and mobile navigation.
- `assets/flying-grid-logo.jpg` — logo supplied by Flying Grid.

## Before publishing

Open `index.html` and replace these contact placeholders with the real business details:

- `CONTACT_EMAIL_HERE` — replace every occurrence with the Flying Grid enquiry email.
- `91XXXXXXXXXX` — replace with the WhatsApp number in international format without `+`, spaces or dashes. Example format: `919876543210`.

The hero and section photography currently load from Unsplash, so visitors need an internet connection to view those photos. For fully self-hosted assets, download appropriately licensed images into `assets/` and update the image URLs.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `flying-grid-website`.
2. Upload `index.html`, `README.md`, and the `assets` folder (keep the same folder structure).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; the published URL appears in the Pages settings.

GitHub Pages can host static HTML/CSS/JavaScript sites on its supported plans. A custom domain is optional and may cost money to register.

## Editing

The website uses plain HTML, CSS and JavaScript; no build step or framework is required. Edit `index.html`, then commit and push the change to GitHub.
